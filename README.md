# irates-bot

irates-bot parses the website irates.am and publishes to Telegram


## Description

irates-bot is a project that parses and publishes news from an Armenian news website irates.am. 
This project is useful for those who want to read news from irates.am in a convenient way by using Telegram channel.
The news feed is in Armenian. 

## Functions

- parses news from irates.am
- extracts the title, date, time, and short summary of a news item

## Tech stack
- python 3
- requests
- BeautifulSoup4
- html.parser
